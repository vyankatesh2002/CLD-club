# CLD Club

Academic and community-focused web project for learning, mentorship, confidence building, and student development.

## Project Overview

CLD Club is a student-oriented web project designed to present programs, mentors, learning activities, and confidence-development resources in a structured and accessible way.

## Key Areas

- Student development
- Mentorship
- Learning programs
- Confidence building
- Community engagement

## Technology

- HTML
- CSS
- JavaScript
- Responsive web design

## Project Type

Academic / community web project.
